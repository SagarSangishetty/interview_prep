Chmod 

n symbolic mode, you can add (+), remove (-), or set (=) permissions:

u: User (owner)
g: Group
o: Others
a: All (user, group, others)
Examples:

chmod u+x file: Adds execute permission to the owner.
chmod g-w file: Removes write permission from the group.
chmod o=r file: Sets others' permissions to only read.
Numeric Mode
Permissions can also be represented using numbers, where each permission has a value:

Read (r): 4
Write (w): 2
Execute (x): 1
To set permissions using numbers, you sum the values for each group (owner, group, others):

chmod 755 file:
Owner gets full permissions (7 = 4 + 2 + 1).
Group and others get read and execute permissions (5 = 4 + 1).


Change ownership --- chown user1 example.txt
Change ownership and group -- chown user1:group1 example.txt

For director use -R option

To redirect output
nohup ./long_running_script.sh > output.log 2>&1 &

The process will ignore the SIGHUP signal (hang up), ensuring it continues running.
The output will be written to nohup.out unless explicitly redirected.
nohup is often combined with & to run the process in the background.
Useful when working over SSH sessions or when you want to close your terminal but keep a task running.

Stdout and STDerror

Stdout is out/result of the command which is executed.

File Descriptor: 1
Default location is terminal but we can redirect it to files
$ echo "Hello, World!" > output.txt
$ echo "Hello, World!" 1> output.txt

STDerror will capture the error message for the command which is executed.

File Descriptor: 2
$ echo "Hello, World!" 2> output.txt

Both Stderror and Stdout in same file

$exho "Hello, World" > output.txt 2>&1>

awk 


The awk command in Linux is a powerful text processing and pattern scanning utility. It is particularly useful for handling structured data, such as columns in a text file or command output. awk allows you to perform various operations like searching, filtering, and transforming data

$0: The entire line.
$1, $2, ...: The first, second, and subsequent fields in the line.
NF: The number of fields in the current record.
NR: The current record number (line number).
$NF: to print last field.

Cut

The cut command in Linux is a text processing utility that allows you to extract sections from each line of input (such as files or command output). It is particularly useful for processing structured text files, like CSVs or TSVs, where data is organized into columns.

-f: Specifies which fields to extract. Fields are typically separated by a delimiter.
-d: Defines the delimiter used to separate fields. The default delimiter is the tab character.
-c: Specifies which characters to extract from each line.
-s: Suppresses lines that do not contain the delimiter.

ls -l | cut -d' ' -f3
ls -l | cut -c1-5

The sed command (short for "stream editor") in Linux is a powerful text processing utility used for parsing and transforming text from a file or standard input. It is particularly useful for automating edits to text files and performing complex text transformations
-e: Allows you to specify multiple editing commands in one sed command.
-f: Allows you to specify a file that contains sed commands.
-i: Edits files in place. This means that the original file will be modified directly. (Be cautious with this option.)
-n: Suppresses automatic printing of pattern space, allowing you to control what is printed with the p command.


Substitution: The s command is used for substitution. It has the format:
s/pattern/replacement/
You can also use delimiters other than /, such as #, which is helpful for paths.
Deleting Lines: The 'd' command deletes lines that match a specific pattern.

Printing Lines: The 'p' command can be used to print specific lines or patterns.

Inserting and Appending Text: The 'i' and a commands can insert or append text before or after a specific line.


 Substituting Text
Example: Replace the first occurrence of "apple" with "orange" in a file.
sed 's/apple/orange/' filename.txt

To replace all occurrences, use the g flag:
sed 's/apple/orange/g' filename.txt

Example: Replace "apple" with "orange" and save the changes directly to the file.
sed -i 's/apple/orange/g' filename.txt

Example: Delete lines containing the word "banana".
sed '/banana/d' filename.txt

Example: Print only lines that match a certain pattern.
sed -n '/apple/p' filename.txt

Example: Insert a line before the first occurrence of "apple".
sed '/apple/i This is a new line' filename.txt

Example: Append a line after every occurrence of "apple".
sed '/apple/a This line is appended' filename.txt

Example: Replace "apple" with "orange" and delete lines containing "banana".
sed -e 's/apple/orange/g' -e '/banana/d' filename.txt

MIN (Minute)

Specifies the minute when the command will run

It ranges from 0 to 59.

HOUR

Denotes the hour of the day when the command is scheduled to execute.

It spans from 0 to 23.

DOM (Day of Month)

Specifies the day of the month for the task.

It ranges from 1 to 31.

MON (Month)

Indicates the month during which the command will be executed.

It varies from 1 to 12.

DOW (Day of Week)

Specifies the day of the week for the task.

It is represented by numbers from 0 to 7, where both 0 and 7 correspond to Sunday.

CMD (Command)

Represents the actual command or script that will run at the scheduled time.
